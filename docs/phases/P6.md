**Windows (Nafew, 30 Oct 2026; `docs/PLAN.md` § E3).** Main pages will open as macOS-style windows. Claude builds the window system separately (`docs/phases/P7W.md`). **You don't build any window UI.** You build normal pages at normal URLs, in a form that system can reuse:

- **Every main page's content is its own component**, in `components/sections/standard/pages/<name>.tsx`. It's a Server Component that fetches its own CMS data. `page.tsx` keeps only the metadata and the shell:

  ```tsx
  export default function AboutPage() {
    return (
      <PageShell>
        <AboutContent />
      </PageShell>
    )
  }
  ```

- **Content must work in a scrolling box about 900 px wide, not only as a full page:**
  - no `Wrapper`, `PageShell`, `Header` or `Footer` inside it;
  - no `h-svh`, `min-h-svh` or full-viewport sections;
  - no `100vw` widths, Lenis hooks or other reliance on the document's scroll;
  - dialogs, such as the `/proof` lightbox, use Base UI's `Dialog`, so they stack and close correctly inside a window.
- **Links stay plain.** Use `@/components/ui/link` and normal routes. Don't add window state, query parameters or modal logic.
