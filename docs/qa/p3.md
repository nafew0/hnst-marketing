## Reproduction

Use Node 24.20.0 and Bun 1.4.4. The isolated Postgres 17 database is `hnst_p3_review` on localhost port 5547. Only disposable fixture secrets were supplied. No GHL credentials or worker were started; queued rows cannot be delivered.

```sh
bunx payload migrate
bun scripts/migrate.ts
NODE_ENV=production bun run seed
NODE_ENV=production bun e2e/p3-setup.ts
bun run check
# Stop any P3 server before the clean no-env build:
rm -rf .next
env -u DATABASE_URL -u PAYLOAD_SECRET -u NEXT_PUBLIC_API_MOCKS bun run build
# Restore the local CMS environment, keep mocks unset:
bun run build
P3_REAL_API=1 bunx playwright test --config e2e/p3-production.config.ts
bunx playwright install webkit
# With NEXT_PUBLIC_API_MOCKS=1 bunx next dev --port 3003 running:
P3_MOCKS_TESTS=1 bunx playwright test --config e2e/p3.config.ts --project chromium --project webkit --project mobile
```

The production config imports the repository's `playwright.config.ts`, preserving every spec and project. It only selects an isolated port (3003), starts the existing production build, and uses two workers. Another developer's original checkout and port 3000 are left untouched.
